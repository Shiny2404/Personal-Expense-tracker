# Personal Expense Tracker
A simple command-line based Personal Expense Tracker developed using Python and SQLite.  
The application allows users to record, manage, search, analyze, and delete their daily expenses.
This project was developed as part of a Python Development Internship Mini Project.

## Project Overview
Managing daily expenses manually can be difficult when there are many transactions to keep track of. The Personal Expense Tracker provides a simple way to store and manage expense records from the command line.
Users can add new expenses, view saved expenses, search expenses by category, calculate total and monthly expenses, delete records, and validate incorrect inputs.

## Features
- Add a new expense
- Enter expense title, amount, category, and date
- View all recorded expenses
- Search expenses by category
- Calculate total expenses
- Calculate monthly expenses
- Calculate yearly expenses
- Delete an expense
- Store expense data using SQLite
- Validate user inputs
- Handle invalid inputs and basic errors
- Simple command-line interface
